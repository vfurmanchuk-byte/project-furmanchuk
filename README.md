# TechFix — облік заявок на ремонт комп'ютерної техніки
 
Вебзастосунок для невеликого сервісного центру: приймання заявок онлайн, ведення
життєвого циклу заявки, призначення майстра, кошторис робіт і запчастин, рахунок,
гарантійний талон і звіти.
 
## Призначення
Замінити паперовий журнал і чати месенджерів єдиною системою обліку ремонтів, щоб клієнт
бачив статус і вартість ремонту онлайн, а майстер — свою чергу заявок.
 
## Структура репозиторію
- `docs/` — проєктна документація (картка проєкту, вимоги, UML, архітектура);
- `src/` — код застосунку (заповнюється на етапі розроблення);
- `docs/assets/` — зображення діаграм і макетів.
 
## Статус проєкту
Практична робота 4: обрано тему, заповнено картку проєкту, сформульовано бачення,
проаналізовано аналоги, створено дошку завдань.
